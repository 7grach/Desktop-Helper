## О проекте

«Пушик» — учебный программный проект: настольное приложение с анимированным персонажем, которое помогает начинающим пользователям осваивать компьютер. Эта версия развивается для представления в вузовском отчёте.

Помощник показывает подсказки поверх окон, выделяет нужные элементы интерфейса и предлагает выполнять задания самостоятельно. Приложение рассчитано на людей с небольшим опытом работы с компьютером, в том числе пожилых пользователей.

## Цель и задачи

Цель проекта — сделать освоение повседневных действий на компьютере более понятным за счёт пошаговых подсказок непосредственно в рабочем окружении пользователя.

Основные задачи:

- обучение работе с мышью, окнами, файлами и папками;
- поиск элементов интерфейса средствами операционной системы;
- проверка выполнения шагов там, где это предусмотрено сценарием;
- объяснение выбранных элементов экрана с помощью ИИ;
- сохранение освоенных навыков и поддержка самостоятельной практики;
- предупреждение о рисках использования программ удалённого доступа.

Пользователь выполняет учебные действия сам. Помощник показывает, куда нажать, и проверяет доступные признаки результата. В отдельных сценариях приложение открывает учебную папку или системное окно выбора файла.

## Возможности

### Пошаговые уроки

| Направление | Примеры заданий |
|---|---|
| Работа с мышью | Одиночный и двойной щелчок, перетаскивание |
| Знакомство с компьютером | Окна, рабочий стол, системные элементы управления |
| Настройки | Изменение громкости и размера текста |
| Интернет и связь | Поиск информации, знакомство с видеозвонками |
| Файлы и папки | Открытие папок, поиск загрузок, выбор документа, фотографии с флешки |

Готовые уроки не требуют подключения ИИ. Для поиска элементов используются UI Automation на Windows и Accessibility на macOS. Доступность конкретных шагов зависит от операционной системы, открытой программы и выданных разрешений. Если автоматическая проверка результата недоступна, сценарий может предусматривать подтверждение пользователя.

### Объяснение выбранной области

Кнопка «Объясни, что это» позволяет выделить мышью непонятный элемент. Приложение обрезает снимок и отправляет модели **только выбранную область**. Ответ содержит описание элемента и его назначения; при недостаточной уверенности помощник предлагает уточнить выделение.

Дополнительно доступны упрощение объяснения, сохранение навыка и самостоятельная практика, если модель предложила подходящее упражнение. При обнаружении признаков опасного действия помощник показывает предупреждение.

В других сценариях ИИ, например при поиске следующего шага свободной задачи, используется снимок всего основного экрана. Снимки обрабатываются в памяти и не записываются приложением на диск.

### Чат и голосовой ввод

Чат позволяет задавать вопросы и получать короткие объяснения. API-ключ вводится в настройках приложения. Кнопка чата доступна и без ключа: из неё можно перейти к подключению ИИ.

Для голосового ввода предусмотрены локальное распознавание Vosk и сервис Whisper. Vosk работает без интернета после загрузки модели; Whisper требует подключения к сервису и соответствующей настройки.

### Прогресс и персонаж

Освоенные навыки отображаются в «Домике навыков». За первый успех создаётся открытка, которую можно сохранить. Поддерживаются три окраса персонажа, анимации, звуковые реакции и настройка размера интерфейса.

### Предупреждения об удалённом доступе

Приложение отслеживает запуск известных программ удалённого доступа, включая AnyDesk, TeamViewer и RustDesk, и уточняет, не выполняет ли пользователь указания незнакомого человека по телефону. Пользователь может отметить программу как доверенную.

Обнаружение такой программы — повод для предупреждения, а не доказательство мошенничества. Эта функция не заменяет антивирус и не блокирует удалённое подключение.

## Технологии и архитектура

Приложение написано на JavaScript без интерфейсного фреймворка и работает на Electron 33. Исходники запускаются из `src/` без сборки интерфейса. Для платформенных функций используются PowerShell и UI Automation на Windows, Swift и Accessibility API на macOS.

| Компонент | Назначение |
|---|---|
| `src/main.js`, `src/preload.js` | Окно приложения, настройки, системные функции и обмен сообщениями с интерфейсом |
| `src/renderer/app.js`, `cats.js` | Интерфейс, поведение и анимации персонажа |
| `src/renderer/scenarios.js`, `coach.js` | Учебные сценарии, подсказки и проверка шагов |
| `src/locate.js`, `src/native/` | Поиск элементов интерфейса средствами ОС |
| `src/files.js` | Учебные папки и файловые сценарии |
| `src/guide.js`, `src/screen-region.js`, `src/renderer/inspect.js` | Захват экрана, выделение области и объяснения |
| `src/llm.js`, `src/http.js` | Обращение к ИИ, выбор моделей и обработка сетевых ошибок |
| `src/stt.js`, `src/renderer/voice.js` | Распознавание речи |
| `src/renderer/home.js`, `playful.js` | Навыки, открытки и игровые элементы |
| `src/calendar.js` | Работа с календарём; напоминания реализованы в `src/main.js` |
| `src/remote-watch.js` | Обнаружение программ удалённого доступа |
| `tools/start.js` | Запуск приложения с учётом платформы |

## Установка и запуск

Требуются Git и [Node.js](https://nodejs.org) 18 или новее. В CI используется Node.js 22.

```bash
git clone https://github.com/7grach/Desktop-Helper.git
cd Desktop-Helper
npm install
npm start
```

При установке загружается локальная модель распознавания речи Vosk размером около 40 МБ. Повторную загрузку можно запустить командой `npm run vosk`.

Если на Windows после установки через npm 12 отсутствует `electron.exe`, выполните:

```powershell
node node_modules\electron\install.js
```

### Разрешения macOS

Для поиска элементов интерфейса требуется «Универсальный доступ», для объяснения экрана — «Запись экрана», для голосового ввода — доступ к микрофону.

При запуске из исходников в системных разрешениях приложение может называться **Electron**. Используемая копия находится в `node_modules/electron/dist/Electron.app` внутри папки проекта.

На macOS `npm start` открывает приложение через системный механизм запуска, чтобы запуск из встроенного терминала Visual Studio Code не зависел от разрешений редактора. Команда завершается, а Пушик продолжает работать. Для выхода выберите «Выйти из Пушика» в настройках приложения. После изменения разрешения на запись экрана полностью перезапустите Пушика.

### Подключение ИИ

1. Откройте «Настройки» в меню персонажа.
2. Выберите сервис: Groq, Claude или OpenRouter.
3. Вставьте API-ключ выбранного сервиса и нажмите «Сохранить».

Ключ хранится в папке настроек приложения; при доступном системном шифровании используется Electron `safeStorage`. Сохранённый ключ не показывается повторно. Пустое поле оставляет прежний ключ. Личный ключ имеет приоритет над настройками команды, в том числе после перезапуска.

Для предварительной настройки можно скопировать `team.example.json` в `team.json`:

```json
{ "provider": "groq", "apiKey": "ВАШ_API_КЛЮЧ", "voice": "whisper" }
```

`team.json` исключён из Git. Если он присутствует при сборке, файл включается в установщик; перед распространением сборки проверьте, что она не содержит личных ключей. Подробности интеграции — в [GROQ-SETUP.md](GROQ-SETUP.md).

В коде также предусмотрено подключение локальной Ollama. Возможность анализа изображений зависит от выбранной модели. Названия моделей и их доступность определяются настройками и сервисом; для OpenAI-совместимых сервисов реализован подбор из доступного списка.

### Сборка установщика

```bash
npm run dist:win   # установщик Windows
npm run dist:mac   # образ DMG для macOS
```

Результаты сборки помещаются в `dist/`.

## Тестирование

Все автоматические проверки запускаются без открытия приложения:

```bash
npm test
```

В текущем наборе 66 тестов. Они покрывают файловые уроки, настройки ИИ, обработку захвата экрана, «Домик навыков», игровые элементы, календарь и напоминания, обнаружение программ удалённого доступа.

Отдельные наборы:

```bash
node --test tools/test-file-help.js
node --test tools/test-ai-settings.js
node --test tools/test-screen-capture.js
node --test tools/test-home.js
node --test tools/test-playful.js
node --test tools/test-calendar.js
node --test tools/test-remote-watch.js
```

Те же проверки настроены в [GitHub Actions](.github/workflows/test.yml) для Ubuntu, Windows и macOS. Прохождение тестов не подтверждает работу всех вариантов системного интерфейса и ответов внешних моделей: разрешения ОС, реальные уроки и качество объяснений дополнительно проверяются вручную.

Для просмотра интерфейса в тестовом режиме можно открыть `src/renderer/index.html` в браузере. Параметр `?onboarded` пропускает тренировку мыши, `?color=white` меняет окрас. В этом режиме системные функции и ответы ИИ заменены заглушками.
